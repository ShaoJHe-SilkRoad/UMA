# UMA 0.9 P1 人工验收指南

此版本只供 P1 人工体验与问题反馈使用。请从 Finder 打开 **`UMA0.9_Enter`**；不需要 Terminal，也不会读取密码、Cookie、Keychain 或浏览器数据。

## 启动与连接

1. 在桌面双击 `UMA0.9_Enter`。
2. 在菜单栏找到 Codex Usage 图标。重复打开启动器不会再启动第二个程序。
3. 首次启动如出现本机连接说明，请选择 **Connect**，再选择 **Allow**。这只允许应用通过本机 Codex app-server 读取账户状态、用量额度与用量摘要；不会要求输入密码，也不会修改账户。
4. 点击菜单栏图标，检查用量面板是否打开。

## 重点检查

- 顶部标题应完整显示为 `Codex Usage`，不应显示省略号。
- 5 小时额度在官方无限状态时应显示 `♾️`，不应误显示为 `100%`。
- 只应出现一行 7 天额度，并显示剩余百分比和重置时间（如官方提供）。
- 点击刷新按钮两次：更新时间应更新，界面不应卡住或重复打开程序。
- 关闭面板后再次点击菜单栏图标，应能重新打开。
- 可在浅色/深色模式下观察文字、按钮、边框和卡片是否清楚可读。

## 如发现问题

请记录：

- 你执行的步骤；
- 面板中可见的错误文字（不要包含账户身份、密钥或原始数据）；
- 是否可以通过关闭再打开面板恢复；
- 是否出现多个菜单栏图标、多个应用或多个异常子进程。

不要继续 P2、P3、长时间 soak、Claude Code 或 Usage Companion 工作。本次人工验收完成后，请等待后续明确指示。
