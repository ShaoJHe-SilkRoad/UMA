The Free dashboard percentage is a truthful provider-rendered display value,
and the remaining display value is derived exactly once from the used value.
It is not an admitted predictor of whether Cursor will accept the next request.
Provider-owned evidence documents cases where the Dashboard percentage and
actual IDE usage-limit enforcement disagree. The browser source therefore
cannot currently satisfy UMA's requirement to represent reliably when work
may pause.

Current Cursor documentation describes two independent paid-plan pools:

1. `Cursor Models`
2. `Other Models`

Those pools are documented but not live qualified. The Founder Free-plan
observation contained one truthful Free-plan pool and does not qualify,
manufacture, merge, or split the paid-plan contract. Paid plans are not
supported by this closeout.

## Reusable research findings

- Provider-controlled Safari authentication can support a technically viable
  Cursor browser-source architecture.
- Account-mode-specific dashboard surfaces exist.
- `/dashboard`, `/dashboard/usage`, and `/dashboard/spending` are a route
  family, not one permanent hard-coded route contract.
- Browser extraction must use bounded semantic provider-rendered labels and
  fail closed on unknown layouts.
- Free-plan percentage is used percentage, not remaining percentage.
- Paid-plan pools require independent legitimate live qualification.
- Broad process argv/environment inspection remains forbidden.

These findings are research assets, not production support. A future visible
percentage alone does not reopen the source.

## Explicit reopen conditions

Cursor may be reconsidered only if at least one of these conditions occurs:

1. Cursor publishes an official structured quota/remaining API or read-only
   CLI source.
2. Cursor documents a stable enforceable remaining-usage contract.
3. Cursor officially resolves the Free-plan Dashboard/enforcement mismatch.
4. A paid-plan account becomes available for legitimate live source
   qualification.
5. The Founder explicitly changes the current source or privacy policy.

Until then: `Cursor remains unsupported.`
