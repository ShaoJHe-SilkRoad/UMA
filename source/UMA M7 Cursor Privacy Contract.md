## Admissible evidence

Durable records may contain only:

- official public documentation URLs and capability classifications;
- exact standard installation candidates and safe presence/absence facts;
- public bundle/CLI version, architecture, file type, owner/mode, signature,
  Gatekeeper and provenance if an artifact is later present;
- documented command names/options without credentials;
- schema field names/types/ranges and normalized semantic classifications after
  a future source passes the live gate;
- operation counts, timing/size bounds, result classes and decision rationale;
- boolean stability, identity, freshness, no-work and teardown results.

## Never access or retain

- password, API key, OAuth/access/refresh token, setup token or authorization
  header;
- cookie, browser profile/session, Keychain secret or authentication database;
- account identity, email, organization, billing/payment or team-member data;
- prompt, response, chat, project, repository, source code or task content;
- raw stdout/stderr, JSON, HTML, DOM, private URL or complete provider payload;
- exact live quota, reset, pool identifier or label in durable evidence;
- Cursor private database, cache, preferences, logs or internal endpoint data;
- credential-derived digest or copied provider session state.

API key, copied token, cookie, Keychain and private endpoint routes are rejected
even when technically possible.

## Authentication classifications

Only these normalized states are admissible:

```text
notRequired
providerAuthenticated
loginRequired
sessionExpired
permissionDenied
unobservable
```

Missing installation is not logout. Network/sandbox/timeout is not an
authentication conclusion. Ambiguous trust, account mode or schema fails
closed and must never become zero quota.

## Safe artifact and process inspection

Use only official exact candidate paths. Process evidence is limited to exact
executable path, a task-owned PID, required parent/child relation, process
count, bounded CPU/RSS/thread/file-descriptor counters and exit/absence.

Forbidden by default:

- broad full-command-line listings;
- unrelated process argv or environment;
- broad process or open-file inventory;
- provider-owned argument/session metadata;
- process memory, injection, packet capture or private binary inspection.

No such broad process inspection occurred in M7-G1.

## Future provider-controlled browser fallback

M7-G1 did not implement or execute this fallback.

## Incident rule

If private material appears unexpectedly, stop immediately. Do not reproduce,
hash, quote, copy or preserve it. Audit only exact retained paths, disclose a
sanitized classification, remove task-owned residue under exact authorization
and resume only with a narrower normalized contract.
