# UMA M7 Cursor Privacy Contract

**Goal:** M7-G1B
**Date:** 2026-08-10
**Decision:** `NO-GO`
**Only next task:** Founder source-direction decision

## Current boundary

M7-G1B is browser-source admission research, not product implementation. M7-G2
remains locked. The task-owned isolated WebKit session reached a
provider-controlled embedded-auth compatibility failure and was rejected after
one Human attempt plus a normal reopen/reload. The separate Safari fallback
completed bounded authenticated source admission and failed the mandatory
used-versus-remaining semantic gate. Provider prompts, tasks and intentional
spend remain 0.

## Admissible evidence

Durable records may contain only:

- official public documentation URLs and capability classifications;
- exact standard installation candidates and safe presence/absence facts;
- public bundle/CLI version, architecture, file type, owner/mode, signature,
  Gatekeeper and provenance if an artifact is later present;
- documented command names/options without credentials;
- schema field names/types/ranges and normalized semantic classifications after
  a future source passes the live gate;
- operation counts, timing/size bounds, result classes and decision rationale;
- boolean stability, identity, freshness, no-work and teardown results.

## Never access or retain

- password, API key, OAuth/access/refresh token, setup token or authorization
  header;
- cookie, browser profile/session, Keychain secret or authentication database;
- account identity, email, organization, billing/payment or team-member data;
- prompt, response, chat, project, repository, source code or task content;
- raw stdout/stderr, JSON, HTML, DOM, private URL or complete provider payload;
- exact live quota/reset values or private provider identifiers in durable
  evidence; only the bounded provider-rendered source label needed for stable
  pool identity may be retained;
- Cursor private database, cache, preferences, logs or internal endpoint data;
- credential-derived digest or copied provider session state.

API key, copied token, cookie, Keychain and private endpoint routes are rejected
even when technically possible.

## Authentication classifications

Only these normalized states are admissible:

```text
notRequired
providerAuthenticated
loginRequired
sessionExpired
permissionDenied
unobservable
```

Missing installation is not logout. Network/sandbox/timeout is not an
authentication conclusion. Ambiguous trust, account mode or schema fails
closed and must never become zero quota.

## Safe artifact and process inspection

Use only official exact candidate paths. Process evidence is limited to exact
executable path, a task-owned PID, required parent/child relation, process
count, bounded CPU/RSS/thread/file-descriptor counters and exit/absence.

Forbidden by default:

- broad full-command-line listings;
- unrelated process argv or environment;
- broad process or open-file inventory;
- provider-owned argument/session metadata;
- process memory, injection, packet capture or private binary inspection.

No such broad process inspection occurred in M7-G1.

## Completed isolated provider-controlled browser attempt

The probe was task-owned, sandboxed, arm64, network-client-only, and used
one visible WebView plus a dedicated persistent WebKit store identifier. It
does not share Safari, Chrome, Cursor, or the default WebKit store. Authentication
is performed only by the Human on official provider pages.

Before the exact authenticated `https://cursor.com/dashboard/spending` route
is independently validated, the probe must not call `evaluateJavaScript`,
register a script message handler, inspect login-page DOM, read cookie or
storage APIs, or emit page content.

After exact-route validation, one atomic extractor may inspect only fixed
Usage-specific landmarks and return a bounded normalized object. It must reject
unknown, duplicate, ambiguous, missing, nonfinite, or out-of-range fields. It
must never return body text, HTML, broad DOM, URL data, identity, credentials,
payment details, invoice history, chats, prompts, projects, or activity
history.

Persistent continuity is proven only by regaining the exact Spending route
after normal probe reopen. Cookies and storage remain opaque. Disconnect and
final cleanup remove only the dedicated task-owned WebKit records.

The isolated session did not regain the exact Spending route after the Human
attempt and normal reopen/reload. It is rejected without another embedded login
attempt. The active Safari fallback must use separate M7-owned temporary
components rather than the frozen Claude BrowserExtension.

## Completed Safari fallback

The task-owned v2 Safari companion used a distinct app/extension identity. Its
static permission surface was limited to native messaging and the recognized
official Cursor dashboard family. Exact route checks ran before landmark
inspection. The Human granted website access only on `cursor.com`; no browser
profile, cookie, token, Keychain secret, or session value was imported or read.

The content layer projected only:

- route, availability and account-mode classes;
- bounded allowlisted pool labels;
- used/remaining/ambiguous semantic classes;
- percentage/ratio/unavailable unit classes;
- reset and billing-cycle presence classes;
- on-demand separation;
- automatic-observation ordinal and private-field count.

The background layer and native extension independently validated the exact key
set, cardinalities and allowlisted enum values before writing the task-owned
receipt. Exact quota values, raw DOM, HTML, URL, identity, billing details and
session material were absent from the handoff and receipt.

The Free-account label and percentage were stable, but its semantic direction
remained `ambiguous`. Missing semantic direction fails closed and must never be
published as used, remaining, or zero. That failure is the final `NO-GO` basis.

## Incident rule

If private material appears unexpectedly, stop immediately. Do not reproduce,
hash, quote, copy or preserve it. Audit only exact retained paths, disclose a
sanitized classification, remove task-owned residue under exact authorization
and resume only with a narrower normalized contract.

screenshot, broad DOM, process argv, or environment output. Final cleanup
disabled and unregistered both task-owned extensions, verified unsigned
extension mode `Off`, removed the exact task-owned probe roots and containers,
and left Safari login data untouched.
