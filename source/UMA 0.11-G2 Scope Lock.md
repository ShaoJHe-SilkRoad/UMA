## Font decision and safety boundary

`Anthropic Serif` is not registered as a system font and no independently
licensed package-safe asset exists in the repository. UMA will not inspect,
copy, extract, or depend on Claude.app fonts. G2 uses the public macOS
system-serif design API, which resolves to the platform editorial serif and
native CJK fallback. Exact values remain system tabular sans. Technical text
alone uses the system monospaced design.

No font file may be added to the package. No exact-font claim may be made.
