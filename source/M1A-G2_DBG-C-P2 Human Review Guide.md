# UMA 0.9 P2 人工复核指南

## 启动

1. 在 Finder 中双击桌面的 `UMA0.9_Enter.app`。
2. 菜单栏只应出现一个 Codex 用量图标。
3. 单击图标打开面板。首次连接仍由你本人确认；应用不会保存密码、令牌或账户身份。

## 请重点检查

1. 面板外缘只有一层轮廓，背景能透过原生玻璃看到。
2. 默认只显示标题、同步状态、额度、Token 概览和底部的“更多信息”。
3. 单击“更多信息”时，“最近任务”和“Token 价值估算”一起展开；再次单击时一起收起。
4. 连续展开/收起多次，面板顶部应固定，不能跳动、塌缩或留下旧尺寸。
5. 打开齿轮设置。设置中不再有隐藏核心卡片的开关；切换语言和“开机时启动”后可正常关闭设置。
6. 五小时为无限时，7 天额度应在上方；“5 小时额度 ∞”应在下方并保持弱化，不显示主进度条。
7. 正常状态显示绿色“已同步 HH:mm”；过期状态显示红色“已过期”。刷新时旧数值继续可见。
8. 额度条应有五个清楚的区段。Pro/Prolite 仅低于 10% 变红；Plus 仅低于 20% 变红。
9. 在浅色和深色外观中各检查一次；文字、百分比、重置时间和按钮都应完整可读。

## 退出与反馈

- 右键菜单栏图标，选择退出。
- 再次双击 `UMA0.9_Enter.app`，确认默认仍是安全的收起状态。
- 若仍看到双边框、面板塌缩、文字截断、错误的红色阈值或刷新后数值消失，请记录当时的外观、语言和操作顺序。

P2 只用于本地人工复核。不要把它当作已发布版本；P3、推送、签名发布和部署仍未开始。
