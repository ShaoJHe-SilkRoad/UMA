# AUV Windows 下一版 · 步骤 2：整体 UI 与动效美化（额度条设计不变）

状态：设计稿（2026-11-11）。在步骤 1 完成并提交之后，由同一执行会话实现。分支：`windows-0.18.6`。

## 原则

- **额度条设计不变：**`AllowanceRow`、`DetailQuotaBar` 的形状、尺寸、圆角、颜色规则和绘制方式都不改，也不给填充宽度加动画。
- **桌面浮窗（Desktop Wizard）外观不变：**这是用户的既有规则。浮窗不在本步范围内；若想改，先单独征求用户同意。
- 深色、浅色、跟随系统、高对比度都要好看且可用。高对比度下不加任何装饰性效果。
- 动效只动透明度和 `RenderTransform`（平移、缩放），不做会触发重新布局的动画。时长 120–220 ms，缓动用 `CubicEase EaseOut`；退出比进入快。
- **尊重系统设置：**`SystemParameters.ClientAreaAnimation` 为 false（Windows“显示动画”关闭）时，所有动效直接跳到终态。
- 中英文文本长度不同，任何布局都不能截断文字。

## 视觉

1. **间距统一到 4/8 网格：**页面边距 24；卡片内边距 16×20；卡片之间 12；同组控件之间 8。
2. **卡片：**
   - 圆角统一为 10。
   - 深色主题用 1px 低对比描边，背景比画布亮一级；浅色主题用柔和投影（`DropShadowEffect` BlurRadius 12、Opacity 0.08、Direction 270、Depth 2）加 1px 描边。
   - 卡片标题与正文的层级更清楚：标题半粗，次要文字用 `MutedBrush`。
3. **左侧智能体列表：**
   - 悬停时背景提亮一级；选中项左侧加 3px 强调色指示条；按下时缩放到 0.98。
   - 拖动排序时，被拖项半透明，插入位置显示 2px 强调线。
   - 列表项里的额度填充保持原样。
4. **顶部栏和底栏：**
   - 按钮统一高度和内边距。
   - “全部刷新”在刷新中显示旋转的刷新图标（替代只改文字），刷新完成后图标停止并回正。
   - 底栏状态文字左对齐，图标按钮间距统一。
5. **设置窗口：**
   - 左侧分区导航与主窗口列表使用同一种悬停和选中样式。
   - 每个分区的分组标题之间有统一间距。
   - 开关、下拉框与标签基线对齐；Claude 的“高级”折叠区用带箭头的展开头。
6. **托盘面板（UsageFlyout）：**与主窗口卡片风格一致，包括圆角、描边和间距；里面的额度条不变。
7. **对话框**（Claude 的“打开浏览器？”和 AUV 自己的窗口）：使用应用主题色和圆角卡片样式；按钮样式与主窗口一致。系统 `MessageBox` 保持系统样式。
8. **焦点可见：**所有可交互控件都有清晰的键盘焦点框（2px 强调色、圆角跟随控件），鼠标点击时不显示。

## 动效

| 位置 | 动效 | 时长 |
|---|---|---|
| 切换智能体页面 | 新内容淡入 + 自下而上 8px 平移；旧内容直接替换（不做交叉淡出，避免重叠） | 180 ms |
| 选中指示条 | 在列表项之间滑动到新位置 | 160 ms |
| 卡片数据更新（新读数到达） | 卡片内容整体做一次 0.6→1 的透明度过渡；数字不做滚动计数 | 150 ms |
| 刷新按钮图标 | 刷新期间持续旋转（1 圈 / 900 ms），结束后补完当前这圈回正 | — |
| 底栏状态消息 | 新消息淡入；旧消息淡出 | 120 / 90 ms |
| 设置分区切换 | 淡入 + 6px 平移 | 150 ms |
| 窗口与对话框打开 | 淡入 + 缩放 0.98→1 | 160 ms |
| 托盘面板弹出 | 淡入 + 自下而上 10px 平移 | 180 ms |
| 悬停 / 按下 | 背景色过渡，按下缩放 0.98 | 100 ms |

## 实现建议

- 在 `App.xaml` 中集中定义样式和动画资源：`CardStyle`、`NavItemStyle`、`AccentFocusVisual`，以及 `FadeInUp`、`PressScale` 等 Storyboard 资源。
- 写一个小的 `Motion` 帮助类：统一读取 `ClientAreaAnimation`；关闭时不播放动画、直接设为终态。
- 动画尽量用附加行为（例如 `Motion.EnterOnLoad="True"`）挂在 XAML 上，不在各处写重复的代码。
- 性能：用现有的 `PerformanceMonitor` 对比改动前后空闲时的 CPU 和内存，空闲 CPU 不得上升。
