# AUV_Win_0.16.3

Windows stable build 20261011.1; application version 0.16.3. macOS remains 0.15.1.

- Unified theme-aware main header, with minimize/maximize/restore/close, native dragging/resizing and Windows 11 Snap Layouts.
- Regular Wizard uses a larger centered icon and agent name, inline subscription level and compact 7d/5h labels. Minimalist is widened from the previous compact revision.
- Wizard right-click offers Exit AUV; double-click opens the main window.
- Persistent Hide tray icon setting. Hiding the icon preserves access to the main window; closing with no tray exits. Windows owns notification-area pinning.
- No change to provider permissions or storage capabilities. Unknown/stale quotas stay hidden; verified zero remains visible.

Validation is recorded with the release package. Existing preferences are retained. No installer, startup service or Windows code signature is included.
