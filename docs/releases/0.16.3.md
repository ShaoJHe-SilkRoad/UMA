# AUV_Win_0.16.3

**Windows stable · version 0.16.3 · build 20261011.1 · Windows 11 x64 · portable ZIP · unsigned.**

[Download AUV_Win_0.16.3.zip](https://github.com/ShaoJHe-SilkRoad/UMA/releases/download/v0.16.3/AUV_Win_0.16.3.zip) · [Install / upgrade](https://shaotinghe.com/auv/install/#windows-installation-guide) · [Release source](https://github.com/ShaoJHe-SilkRoad/UMA/tree/8ed7b53ca421daf8006b02c22d1dcbca724fc148/windows)

- Unified theme-aware main header with working window controls, native drag/resize and Windows 11 Snap Layouts.
- Refined Regular/Minimalist Desktop Wizard: larger centered icon, inline subscription level and compact 7d/5h labels. WorkBuddy compact balances retain their four-character limit.
- Wizard right-click offers Exit AUV; double-click opens AUV. Settings can hide or restore the tray icon and retain that preference. Windows controls tray pinning beside the clock.
- Only valid, fresh fetched quotas appear; verified zero remains visible. Codex usage is read-only. WorkBuddy official-page Credit sync remains experimental and requires optional Microsoft Edge WebView2 Runtime.

Extract the **complete ZIP**, then run **AUV.exe**. The .NET 10.0.12 desktop runtime is included; no separate .NET installation is needed. Quit the old copy before upgrading; preserve `%LOCALAPPDATA%\AUV.Windows.UI.Preview`. **Ctrl+Shift+Q** exits completely.

These are developer checks, not independent QA or clean-machine certification. Live provider sync, receiving-client/Ultra execution, ARM64 and exhaustive OS scaling were not requalified. Claude/Antigravity live transports remain unavailable; Sectorium Windows storage operations are disabled. ThreadOS generates/copies instructions without dispatch.

**Integrity:** 65,447,377 bytes; SHA-256 `bc1577aae1d3ffdc3e3b104de15c6649ab4fb83f452a04865d548002f432085a`. See HASHES.txt and RELEASE-MANIFEST.json. Windows package is **NotSigned**; no installer, startup service or signing-reputation claim.
