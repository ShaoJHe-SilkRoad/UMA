# UMA 0.15.0

UMA, ThreadOS and Sectorium share a restrained surface and border treatment in light and dark appearances. Existing control positions, dimensions, provider colors and keyboard routes are retained.

ThreadOS continues to generate and copy the same deterministic team-model command. Sectorium retains its verified identity, state ownership and storage safeguards. This visual update adds no storage action or automation.

The local release candidate uses build 2026100901. Packaging is separate from installation, public release and real-disk validation. Those actions are not performed by this task.
