# AUV Mac 0.16.3

**macOS 14+ · Apple silicon · build 2026101101.**

The menu-bar Quick Panel is simpler: the Storage menu is removed, and Scan, Refresh, Desktop Wizard and Settings sit together at the upper right. Existing preferences and the other app pages are retained.

[Download AUV_Mac_0.16.3.zip](https://github.com/ShaoJHe-SilkRoad/UMA/releases/download/v0.16.3/AUV_Mac_0.16.3.zip) · [Install or upgrade](../INSTALLATION.md) · [Checksums](https://github.com/ShaoJHe-SilkRoad/UMA/releases/download/v0.16.3/AUV_Mac_0.16.3.HASHES.txt)

The package keeps the `UMA.app` filename for compatible upgrades. This is a Mac update; [Windows 0.16.3](https://github.com/ShaoJHe-SilkRoad/UMA/releases/tag/v0.16.3) remains available separately.

This change does not qualify Sectorium disk operations. Those tools remain experimental, with real-device operation unverified for this release. Native model activation and live Ultra execution are also not established by a copied instruction. Current package identity, signing and notarization are recorded in the attached AUV_Mac_0.16.3.RELEASE-MANIFEST.json.
