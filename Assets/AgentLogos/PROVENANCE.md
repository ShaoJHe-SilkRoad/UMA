# Desktop Wizard brand assets

Local template resources; no runtime downloads. Brand ownership remains with the respective vendors.

- Codex: OpenAI blossom from https://cdn.openai.com/brand/OpenAI-Logos-2025.zip, linked by https://openai.com/brand/. Original SVG preserved. Runtime SVG changes only the canvas to crop empty margins; paths are unchanged.
- Claude Code: official documentation symbol from https://code.claude.com/docs/en/overview. Exact first path from the official light.svg wordmark retained on a 28-by-28 canvas; no redrawing. Original wordmark preserved.
- WorkBuddy: https://download.codebuddy.cn/web/workbuddy/fda13a892959d1a490343dc2db27e56895f00e4b/assets/logo.svg linked by https://www.workbuddy.cn/. Original preserved. Template retains original foreground path, two transformed eye rectangles and clipping geometry; removes background circle and gradient, sets foreground black for semantic template tint. No provider admission is implied.
- Google Antigravity: https://antigravity.google/favicon.svg, the site's declared SVG icon. Original preserved. Template retains the exact first path, the mark's silhouette, on an 88-by-88 canvas cropped to it; drops the background circle, the colour blur layers and their mask, and sets the path black for semantic template tint.

All runtime marks use the existing connection/manual semantic color. Alpha geometry supplies a restrained silhouette shadow; old letter badges had no independent glow implementation. Negative space remains transparent.
